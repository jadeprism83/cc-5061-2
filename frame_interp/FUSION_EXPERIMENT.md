# 中间帧融合实验

对照 **前向扭曲按层择源** 与 **反向取样 + 联合可见性** 两条中间帧构造路线，
量化错误遮盖面积、重影面积与空洞率，并用同一双向运动场做逐帧对照。
全部数字由 `tests/run_fusion_experiment.py` 生成，`--verify` 会回读落盘 PNG /
掩码逐项复算，不一致即报错。**仓库不手写数据。**

## 1. 两条路线与五种策略

共享同一运动估计（`interp.core.estimate_bidirectional_flow`），只替换“目标时刻
取哪个源、两侧怎么合并”这一层：

| 方法 | 构造 | 遮挡处理 |
| --- | --- | --- |
| `warp_blend` | 双向前向扭曲后透明平均 | 无（基线，必产生重影/错误遮盖） |
| `layered` | 前向 splat + 按层择源（`core` 生产路径） | 碰撞格按遮挡状态/前景评分裁决，冲突标 0.35 可信 |
| `backward` | 反向多起点不动点取样，按流一致性取一侧 | 无两侧联合可见性，冲突仅按评分 |
| `joint` | 反向取样 + 联合可见性与两侧权重后选定 | 前向碰撞胜负作为可见性证据，进入两侧权重 |
| `vis_switch` | 按可见性切换：明确处用反向样本，其余回退分层 | 可见性明确才切，冲突/多解回退 `layered` |

原型在 `interp/fusion.py`，指标在 `interp/fusion_metrics.py`，场景在
`interp/fusion_scenes.py`。

## 2. 场景

同一前景轮廓（非对称 C 形，带右侧开口与顶部缺口）分别扫过两种背景：

- `sweep_solid` / `sweep_texture`：同一轮廓扫过单色 / 细纹背景；
- `crossing_solid` / `crossing_texture`：交叉前景（洋红在前、青色在后，中点完全重叠）；
- `reveal_solid` / `reveal_texture`：显露背景（方块右移，左侧背景在 I0 被遮挡、I1 可见）。

每个场景 5 帧，中间真值 t = 0.25 / 0.50 / 0.75 由同一渲染器直接绘制。

## 3. 指标定义（逐像素，可复算）

- **错误遮盖**（`wrong_cover`）：真值背景格被判成前景色（纯色前景，容差 0.25）。
- **漏遮**（`under_cover`）：真值前景格被判成背景。
- **重影面积**（`ghosting`）：真值背景格出现前景色，或与真值本帧同格颜色之差超过
  真值局部 7×7 标准差的 3 倍（下限 0.10）。用局部基准是为了不让细纹背景的正常
  深浅起伏被误报成重影。
- **空洞率**（`hole_ratio`）：输出中没有真实源样本的格占比；命中/补全掩码随结果
  一起落盘（`*_hitmask.png` / `*_fillmask.png`），空洞率可由 PNG 直接数出来。
- **边缘**：真值前景轮廓外扩 2px 带内的 MAE 与梯度方向紊乱。

## 5. 结论与选择依据

- 跨场景平均：重影面积最低 `warp_blend`（0.601%）；空洞率最低 `vis_switch`（0.117%）；边缘 MAE 最低 `backward`（11.56）；帧 MAE 最低 `backward`（1.41）；最快 `warp_blend`（0.06s）。
- 重影的区分度只来自细纹背景：单色场景各方法重影都 <0.05%，因为背景无纹理、错误遮盖直接表现为前景残留。仅看细纹场景，重影最低的是 `warp_blend`（平均 1.166%）。
- `warp_blend` 的帧 MAE 并非最差，但 **漏遮** 最重（1.731%）：不做遮挡裁决，交叉重叠处的透明平均把前景稀释成背景色。
- `layered` 两侧冲突率最高（9.354%），它把每个被两侧样本争夺的格都记为碰撞；`backward`/`joint` 在冲突格只保留一个解，冲突率（2.003%）不直接可比。
- `backward` 帧 MAE 最低（1.41），但空洞率最高（2.067%）：只接受不动点闭环收敛解，未收敛处留空。`joint` 在同一批空洞上加可见性权重，未减少空洞，边缘 MAE 反而更高（14.55 vs 11.56）。
- `vis_switch` 空洞率最低（0.117%）：反向解可用的格取反向样本，其余回退分层命中，把反向取样的空洞补上；错误遮盖随之升到 0.167%。
- 反向取样代价：`layered` 平均 0.09s，反向取样系列 0.33s，约 3.7 倍。

**选择**：默认生产路径保留 `layered`（快、无额外假设、空洞与重影都在可接受量级）；需要压空洞且能接受约 3 倍耗时时用 `vis_switch`；`joint` 在本批场景没有相对 `backward` 的稳定优势，只作为可见性权重的研究原型，不进入默认路径。交叉场景的漏遮（1%–2%）来自重叠区只能二选一，属数据本身的不可见部分，不能靠融合策略消除。以上结论仅对合成序列成立，阈值与权重见第 8 节。

## 6. 同一双向运动输入的逐项评估（空洞 / 碰撞 / 边缘）

以交叉与显露场景为例，三时刻（t=0.25/0.50/0.75）逐帧观察：

- **空洞**：`backward` 与 `joint` 空洞率在所有时刻都高于前向方法（交叉实心
  2.2%–4.7%，前向约 0.9%–3.5%），且随 t 增大而升高——反向解需要不动点收敛，
  重叠区每格只保留一个解，收敛不到就留空。`vis_switch` 把反向解不可用的格
  回退成前向命中，中点交叉处空洞从 3.45%（`layered`）降到 0.01%。
- **碰撞**：`layered` 在交叉场景把 10%–15% 的像素记为两侧冲突，`joint`/`backward`
  只有 2%–6%——差异主要来自记法：`layered` 记录“样本争夺”，反向方法记录
  “取哪一个解”。两者不能直接横比，只能各自和自己的空洞率一起看。
- **边缘**：`backward` 的边缘 MAE 通常最低（交叉实心分别为 1.6 / 7.1 / 24.3），
  `layered` 的边缘 MAE 与梯度紊乱最高（8.3 / 19.4 / 32.5），因为分层 splat 在
  重叠处做硬遮挡切换，边缘带内出现台阶。`joint` 加了可见性权重后边缘 MAE 反而
  高于 `backward`（10.0 / 12.0 / 21.9），说明当前权重会在边缘附近选错源。

## 7. 限制（不可见内容）

- 交叉前景在中点完全重叠时，纯双向流不含深度信息，`joint` / `vis_switch` 的
  可见性胜负来自前向碰撞的前景评分，两侧打平时仍是**确定性并列**，可信度被压到
  ≤0.35，并未恢复真实隐藏细节。
- 显露背景区域在 I0 被遮挡、I1 可见，反向取样能采到；但两侧都未观测的区域只能
  有限扩散补全，补全区不可信。
- 反向取样对运动场做多起点不动点迭代：代价约为 `layered` 的 2–4 倍，且大位移
  依赖起点覆盖。当前起点取自全场位移分布 + 零位移 + 最大位移方向，属于待验假设
  （见第 8 节）。

## 8. 待验假设（单列，不当作结论）

1. 反向取样的多起点集合（位移频率 Top-N + 零位移 + 最大位移）是否足以覆盖所有
   真实对应点；未覆盖时会退化成静态解。
2. `joint` 的可见性权重（流一致性 × 碰撞胜负 × 归一化前景评分）中三项的相对
   权重未经标定，只在合成序列上成立。
3. 边缘阈值（局部 3σ、下限 0.10）与背景纹理幅度相关，换真实视频需重标。
